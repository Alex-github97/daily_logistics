Modulo de analítica - Proyecciones - Indicadores.

Este modulo debe tener una sección de analítica configurable de métricas tipo powerbi. donde uno seleccione la data de la que quiere extraer el dato, seleccionar el tipo de grafico, calcular alguna métrica con campos calculados (esto podría usar un lenguaje de calculo potente, que permita realizar métricas estadísticas avanzadas de ser necesario)
